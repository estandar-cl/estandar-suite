# Demo Image Prompts

Las imágenes originales de Codrops accesibles quedaron descargadas en esta carpeta. Los screenshots directos de CodePen devolvieron 403 y los assets de Apple/Rivian no deben copiarse por marca/licencia. Para reemplazar los fallbacks por imágenes generadas, usar estos prompts en ChatGPT Classic o el generador visual disponible.

## Pinned Image Reveal / GSAP Mask Reveal

Prompt:
```
Create a cinematic full-bleed editorial photograph for a scroll-driven product hero. Subject: abstract premium electric vehicle silhouette or architectural object, no logos, no recognizable brand, dark background, soft studio lighting, glossy reflections, wide angle, high contrast, lots of negative space for centered white headline text. 16:9, ultra clean, premium Apple/Rivian-inspired mood without copying any brand asset.
```

## ScrollTrigger Image Zoom

Prompt:
```
Create a high-resolution hero image designed for a scroll zoom reveal. Subject: modern minimal interior detail or product detail, sharp center focus, subtle foreground blur, deep shadows, warm highlights, no text, no logos, premium commercial photography, suitable for mask reveal and zoom animation. 16:9.
```

## Container SplitText

Prompt:
```
Create three editorial images for horizontal storytelling panels. Theme: premium digital product launch, abstract architecture, refined gradients, cinematic lighting, no logos, no readable text, each image distinct but part of the same campaign. Vertical 4:5 crop, suitable for side-by-side sticky panels with large typography.
```

## Scroll Synced Carousel

Prompt:
```
Create a set of ten cohesive gallery images for a scroll-synced carousel. Theme: modern product/story campaign, alternating close-up details, environmental scenes, and abstract textures, no logos, no people with identifiable faces, premium neutral color palette, editorial but commercial. 4:5 crop, consistent lighting.
```

## Apple/Rivian-Style Product Storytelling

Prompt:
```
Create a neutral premium product storytelling image set inspired by high-end product landing pages, without copying Apple or Rivian. Include: one cinematic full-bleed hero, three detail close-ups, three environmental wide shots, and three abstract material textures. No logos, no brand-specific vehicle/device shapes, no text. Clean, high contrast, modern, suitable for web scroll animations.
```
