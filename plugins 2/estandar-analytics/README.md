# Estandar Analytics

Self-hosted, privacy-first analytics para WordPress. Tracking de sesiones, fuentes, pageviews, eventos y conversiones sin SaaS externo. Versión unificada: 13.0.173.

## Capacidades

- Session tracking (cookie `ea_sid`), pageviews, events, conversions, referrers, devices, aggregates, ads_daily (8 tablas).
- Funnel y dashboard views.
- Import de Meta Ads a `ea_ads_daily` (spec `ESTANDAR_META_IMPORT_V1`, archivada en `docs/historico/`).
