# Estandar Destinations

Motor de destinos externos para datos del ecosistema Estandar. Centraliza exportaciones hacia webhooks, hojas de cálculo y CRMs. Versión unificada: 13.0.173.

## Capacidades

- Colas de destino: `estandar_oci_queue`, `estandar_oci_queue_meta`.
- Google Ads destination (adapter), webhook destination, scheduler, health monitoring.
- Integración prevista con `Core\Destinations`.

## Estado en la Suite

- **Clasificación portfolio:** MOTOR TRANSVERSAL (híbrido) — **CONSOLIDAR EN Core\Destinations**. Duplica signal-core y estandar-leads (triple Google OCI).
