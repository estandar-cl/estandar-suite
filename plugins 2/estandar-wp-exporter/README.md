# Estandar WP Exporter

Exporta plugins y themes instalados como ZIP descargable desde wp-admin, por lotes (AJAX) y con ZIP temporal seguro. Versión unificada: 13.0.173.

## Descripción

Herramienta administrativa para exportar plugins y themes instalados como archivos ZIP completos, conservando su estructura original. Orientado a:

- Entornos con hosting compartido o restrictivo
- Sitios sin acceso directo al filesystem
- Procesos de respaldo, migración o auditoría técnica
- Uso interno y administrativo (no frontend)

Principios de diseño: no modifica contenido ni base de datos, no afecta el frontend.
